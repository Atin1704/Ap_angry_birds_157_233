**How to set up ,run and test the project**-

**Method 1**
1.Download the zip file
2.Create a folder anywhere(ideally on desktop)
3.Move the zip file inside that folder
4.Extract the zip file
5.Open the folder in an ide (Preferred-Intellij Idea)
6.Navigate to lwjgl3/build/src/main/java/com.birds.lwjgl3/Lwjgl3Launcher
7.A green run icon should be on your top right corner (for Intellij)
8.Click on it
9.The project will build and start running on your screen.

**Method 2**-
1.Download the zip file
2.Create a folder anywhere(ideally on desktop)
3.Move the zip file inside that folder
4.Extract the zip file
5.Go to the terminal
6.Navigate to the directory where the project is stored (use cd command)
7.Enter ./gradlew build && ./gradlew run
8.The project will build for some time and then start running
